# ПЗ №4 — Selenium: вариант 2 (BMI)

Автотесты калькулятора https://www.calculator.net/bmi-calculator.html.

## Требования

- Python 3.10+
- Google Chrome
- Интернет

## Установка и запуск

В корне проекта:

```bash
python -m pip install -r requirements.txt
python -m pytest -v
```

Selenium 4 автоматически управляет ChromeDriver через Selenium Manager (при наличии необходимых условий и доступа к сети).

## Сценарии

1. Корректный расчёт BMI: 5 наборов роста и веса (метрическая система).
2. Проверка категорий BMI и переходов между ними (4 набора).
3. Граничные и неправильные данные: 0, отрицательные числа, буквы, пустые поля, чрезмерно длинное число; максимальный возраст 120 лет.
4. Работа с американскими единицами (футы, дюймы, фунты) и сверка результата.
5. Формат вывода: округление BMI до десятых.
6. Проверка кнопки Clear.

## Архитектура

- `pages/bmi_page.py` — Page Object: URL, локаторы, действия, ожидания, чтение результата; без `assert`.
- `tests/test_bmi.py` — проверки через pytest, независимые друг от друга.
- `conftest.py` — создание и закрытие Chrome.

Ожидания реализованы через `WebDriverWait`; `time.sleep()` отсутствует.

## Результат проверки

При запуске пользователем на Windows с Python 3.13.9 и Google Chrome все исходные 21 теста завершились успешно: `21 passed in 130.77s` (11.11.2026). После добавления теста максимального возраста требуется повторный запуск (22 теста).

Переключение систем измерения выполняется через `?ctype=metric` и `?ctype=standard`. Если разметка сайта изменится, локаторы необходимо обновлять в `pages/bmi_page.py`.
